# Guía de Identidad Visual - CIVILIZACIÓN ALGORÍTMICA

## Filosofía de Diseño

### Concepto Central
**"El futuro no se predice. Se construye."**

CIVILIZACIÓN ALGORÍTMICA representa la convergencia entre inteligencia artificial responsable y soberanía tecnológica europea. La identidad visual transmite:

- **Tecnología avanzada**: Soluciones de vanguardia
- **Arquitectura visual de centro de mando**: Control y supervisión
- **Sofisticación editorial**: Elegancia y profesionalismo
- **Minimalismo funcional**: Claridad y eficiencia
- **Redes de inteligencia**: Conectividad y colaboración

### Valores Fundamentales

1. **Inteligencia Responsable**
   - IA ética y transparente
   - Supervisión humana constante
   - Decisiones explicables

2. **Soberanía Tecnológica**
   - Control total sobre datos y procesos
   - Independencia de proveedores
   - Portabilidad garantizada

3. **Transparencia**
   - Trazabilidad completa
   - Auditoría permanente
   - Decisiones documentadas

4. **Verificación**
   - Validación independiente
   - Pruebas rigurosas
   - Evidencias verificables

5. **Apertura**
   - Código abierto
   - Estándares abiertos
   - Interoperabilidad

6. **Sostenibilidad**
   - Optimización de recursos
   - Presupuesto cero
   - Eficiencia energética

## Principios de Diseño

### 1. Claridad ante Decoración
- Cada elemento visual debe tener un propósito funcional
- Evitar elementos decorativos que no aporten información
- Priorizar la legibilidad y comprensión

### 2. Consistencia ante Variedad
- Usar tokens CSS para mantener coherencia
- Aplicar patrones de diseño uniformes
- Mantener jerarquía visual clara

### 3. Función ante Forma
- La estética debe servir a la usabilidad
- Los controles deben ser intuitivos
- Las acciones deben ser evidentes

### 4. Accesibilidad ante Estilo
- Cumplir WCAG 2.2 nivel AA como mínimo
- Garantizar contraste suficiente
- Permitir navegación por teclado
- Respetar preferencias de usuario

### 5. Rendimiento ante Efectos
- Animaciones sutiles y con propósito
- Respetar prefers-reduced-motion
- Optimizar tiempos de carga
- Minimizar uso de recursos

## Tipografía

### Familias Tipográficas

#### Inter (Sans-serif)
- **Uso**: Texto de aplicación, controles, tablas, textos técnicos
- **Características**: Legibilidad, neutralidad, modernidad
- **Pesos**: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)

#### Playfair Display (Serif)
- **Uso**: Titulares destacados, frases conceptuales, elementos de identidad
- **Características**: Elegancia, sofisticación, carácter editorial
- **Pesos**: 600 (semibold), 700 (bold)

#### JetBrains Mono (Monospace)
- **Uso**: Código, datos técnicos, valores numéricos
- **Características**: Claridad, precisión, legibilidad técnica
- **Pesos**: 400 (regular), 500 (medium)

### Jerarquía Tipográfica

```
H1 (Page Title): Playfair Display, 2.25rem, Bold
H2 (Section Title): Playfair Display, 1.875rem, Semibold
H3 (Card Title): Inter, 1.25rem, Semibold
H4 (Subsection): Inter, 1.125rem, Semibold
Body: Inter, 1rem, Regular
Small: Inter, 0.875rem, Regular
Caption: Inter, 0.75rem, Regular
Code: JetBrains Mono, 0.875rem, Regular
Metric: JetBrains Mono, 1.5rem, Bold
```

### Reglas Tipográficas

1. **Interlineado**: 1.5 para texto de cuerpo, 1.2 para títulos
2. **Espaciado entre párrafos**: 1rem
3. **Longitud máxima de línea**: 75 caracteres
4. **Alineación**: Izquierda para texto, centro para títulos hero
5. **Mayúsculas**: Solo para labels y secciones pequeñas

## Iconografía

### Principios
- Usar iconos de Lucide React para consistencia

## Espaciado

### Sistema de Espaciado

```
xs: 0.25rem (4px)  - Espaciado mínimo
sm: 0.5rem (8px)   - Espaciado pequeño
md: 1rem (16px)    - Espaciado medio
lg: 1.5rem (24px)  - Espaciado grande
xl: 2rem (32px)    - Espaciado extra grande
2xl: 3rem (48px)   - Espaciado doble extra grande
```

### Reglas de Espaciado

1. **Entre elementos relacionados**: sm (0.5rem)
2. **Entre secciones**: lg (1.5rem)
3. **Entre páginas**: xl (2rem)
4. **Padding de tarjetas**: lg (1.5rem)
5. **Padding de página**: xl (2rem)
6. **Gap en grids**: lg (1.5rem)

## Bordes y Sombras

### Bordes

#### Radios
```
sm: 0.25rem (4px)   - Elementos pequeños (inputs, badges)
md: 0.5rem (8px)    - Elementos medianos (botones, tarjetas pequeñas)
lg: 0.75rem (12px)  - Elementos grandes (tarjetas, modales)
xl: 1rem (16px)     - Elementos extra grandes (hero, secciones)
full: 9999px        - Elementos circulares (avatars, badges)
```

#### Colores de Borde
- **Normal**: `var(--ca-color-border)` (#2A3548)
- **Hover**: `var(--ca-color-border-hover)` (#3D4F6A)
- **Focus**: `var(--ca-color-border-focus)` (#C6F86E)

### Sombras

```
sm: 0 1px 2px 0 rgba(0, 0, 0, 0.3)    - Elevación mínima
md: 0 4px 6px -1px rgba(0, 0, 0, 0.4) - Elevación media
lg: 0 10px 15px -3px rgba(0, 0, 0, 0.5) - Elevación alta
xl: 0 20px 25px -5px rgba(0, 0, 0, 0.6) - Elevación máxima
```

### Uso de Sombras
- **sm**: Inputs, badges, elementos interactivos pequeños
- **md**: Tarjetas, dropdowns, tooltips
- **lg**: Modales, popovers, menús desplegables
- **xl**: Diálogos críticos, overlays importantes

## Animaciones y Transiciones

### Duraciones

```
fast: 150ms   - Hover, focus, cambios de estado rápidos
base: 250ms   - Transiciones estándar, apertura/cierre
slow: 350ms   - Animaciones complejas, transiciones de página
```

### Easing

```
cubic-bezier(0.4, 0, 0.2, 1) - Standard (material design)
cubic-bezier(0, 0, 0.2, 1)   - Decelerate (entrada)
cubic-bezier(0.4, 0, 1, 1)   - Accelerate (salida)
```

### Reglas de Animación

1. **Propósito**: Toda animación debe tener un propósito funcional
2. **Sutileza**: Preferir transiciones sutiles sobre efectos dramáticos
3. **Duración**: Máximo 350ms para transiciones de UI
4. **Accesibilidad**: Respetar `prefers-reduced-motion`
5. **Rendimiento**: Animar solo `transform` y `opacity` cuando sea posible

### Ejemplos de Uso

#### Hover en Botones
```css
transition: all var(--ca-transition-fast);
transform: translateY(-1px);
box-shadow: var(--ca-shadow-md);
```

#### Apertura de Modal
```css
animation: ca-fade-in var(--ca-transition-base);
```

#### Cambio de Estado
```css
transition: background-color var(--ca-transition-fast);
```

#### Variantes
- **Primary**: Fondo accent, texto inverse (acciones principales)
- **Secondary**: Borde border, texto primary (acciones secundarias)
- **Ghost**: Sin fondo, texto secondary (acciones terciarias)

#### Tamaños
- **sm**: px-3 py-1.5 text-xs (controles compactos)
- **md**: px-4 py-2 text-sm (estándar)
- **lg**: px-6 py-3 text-base (acciones destacadas)

### Tarjetas

#### Estructura
```
┌─────────────────────────┐
│ Header (opcional)       │
├─────────────────────────┤
│                         │
│ Content                 │
│                         │
└─────────────────────────┘
```

#### Variantes
- **Standard**: Borde normal, padding lg
- **Elevated**: Sombra md, borde hover
- **Interactive**: Cursor pointer, hover state

### Inputs

#### Estados
- **Default**: Borde border, fondo tertiary
- **Focus**: Borde accent, shadow ring
- **Error**: Borde error, mensaje de error
- **Disabled**: Opacidad 0.5, cursor not-allowed
